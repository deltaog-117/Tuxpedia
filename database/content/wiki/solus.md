### Overview

**Solus** is an independent Linux distribution for the desktop, built from scratch rather than derived from Debian, Fedora or Arch. Its goal is a cohesive, polished and fuss-free experience: install it, and have a usable computer with a sensible set of applications.

It is known as the original home of the **Budgie** desktop, and it offers Budgie, GNOME, Xfce and KDE Plasma editions. Solus uses a **curated rolling release** model, where packages are updated continuously, but only after the team has chosen and tested them.

### Key Features

#### Curated rolling releases

There are no big version upgrades. Updates arrive as they pass testing, and the team periodically publishes new installation images, named after ideas such as "Serenity" or "Opportunity", so that fresh installs start close to the current state. Solus 4.9 "Serenity", released in April 2026, shipped Linux 6.18, Mesa 26, GRUB 2.14 and LUKS2 support in the installer. The default privileged group changed from `sudo` to `wheel`.

#### eopkg

Software is managed with **eopkg**, a package manager inherited from the PiSi system created for Pardus Linux. The repository is smaller than those of big distributions, because the team packages what they can maintain well, and Flatpak is supported to cover the rest.

#### Budgie and friends

The Budgie edition, version 10.9.4 in Solus 4.9, is the flagship. The next major Budgie version is expected to drop X11 support in favour of Wayland. GNOME, Xfce and KDE Plasma editions use recent upstream versions, for example Plasma 6.6.

#### A smooth first run

A graphical installer, a software centre with driver management and sensible defaults keep the first experience simple. The 4.9 release also brought installer upgrades.

#### A shift to new technology

Solus announced it would explore re-basing its next generation on the technology of **Serpent OS** (now AerynOS), whose package manager **moss** uses atomic updates. Reports differ on how firm the plan is, and no release date for a Solus 5 is known. Follow the project's own announcements for the current state.

### Who It Is For

- **Desktop users** who want a consistent, curated system.
- **Budgie fans**, since the project grew up around that desktop.
- **People who prefer fewer, well-chosen packages** over a giant repository.

It is not designed for servers or for people who need very specific, niche software.

### History

- **2012**: Ikey Doherty begins the project as **Evolve OS**.
- **2015**: The project is renamed **Solus**. Its Budgie desktop is developed alongside it.
- **2018**: Founder Ikey Doherty leaves and a new team, led by Joshua Strobl, takes over.
- **2022**: Budgie development moves to the independent Buddies of Budgie project.
- **2026**: Solus 4.9 "Serenity" is released.

### Comparison

| Feature | Solus | Linux Mint | Fedora |
| :--- | :--- | :--- | :--- |
| **Origin** | Independent | Ubuntu or Debian | Independent |
| **Release model** | Curated rolling | Fixed (follows Ubuntu LTS) | Fixed, about every six months |
| **Package manager** | eopkg | APT | DNF |
| **Flagship desktop** | Budgie | Cinnamon | GNOME |
